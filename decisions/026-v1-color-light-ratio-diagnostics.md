# 决策 026：彩光合格帧比例可调与颜色诊断

- 日期：2026-11-18
- 状态：代码实现完成；专项 pytest 受当前 Python 环境缺少 pytest/pygments 阻塞，语法编译已通过；现场验收未执行。
- 闭环：用户反馈彩光检测不应因单帧颜色误差立即失败，且绿光容易响应不足。
- 实施：管理员页面新增 50%–100%、步进 5%、默认 85% 的彩光合格帧比例控件；设置通过 MainWindow → CheckInTab → ColorLivenessDialog → ColorLightConfig 传递，不持久化。
- 规则：比例仍只用于颜色窗口结算；人脸、身份、被动活体、输入和设备异常仍是硬门禁。
- 诊断：彩光窗口进度显示当前比例阈值，失败时继续展示失败颜色、有效帧、达标帧和位移丢弃帧。
- 绿光处理：将窗口绿光背景由 `#1f9d55` 提升为 `#20d968`，同时提升红光为 `#f02020`，使三色刺激更均衡；没有设置绿光专属宽松阈值。
- 限制：当前无法据代码单独证明绿光反射差；仍需实机记录三色的有效样本、达标样本和色差，再决定是否需要 ROI、曝光或颜色专属阈值优化。
