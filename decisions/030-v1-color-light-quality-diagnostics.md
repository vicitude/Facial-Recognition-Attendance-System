# 决策 030：彩光画质容错与分色诊断

- 日期 2026-11-20。彩光专项 48 项隔离测试通过，客户设备待复测。
- 客户出现红光达标 2/2 后因画质提前退出，也出现红光有效 39 帧、达标 0 帧的情况。两类现象需要不同的排查方式，双方设备也不同。
- 挑战色阶段检测到单脸但画质不足时跳过该帧，继续采样至原 2 秒截止。画质丢弃与位移丢弃都不进入合格率分母。白光基线、最终白光及有效帧的身份与被动活体校验仍执行原规则。
- 管理员管理页面显示最近一次诊断，逐色列有效、达标、位移丢弃、各画质原因和目标通道增量中位数与峰值。只保留在当前应用的内存中，无姓名、工号或可回看的图像。检测窗口按画质原因给出实时提示。
- 用受控时钟、合成颜色及 Qt 替身验证恢复、样本不足、色差不足、相机归还、门禁及管理员界面。测试使用项目解释器和 `--noconftest`，现场设备与光照影响仍需测量。
