# 决策 032：彩光检测记录环境灯光状态

## 状态
已实施（v1）

## 背景
客户失败日志包含关灯测试；关灯时 MiniFASNet 被动活体拒绝，不能与彩光响应阈值问题混为一谈。

## 决策
每次彩光检测开始前由用户选择环境灯光状态：正常灯光（normal，默认）、关灯（off）、其他/不确定（other）。取消选择则取消本次彩光检测。失败日志追加 environment_light 字段；历史日志缺失时按 unknown 处理，不自动推断。

## 理由
环境灯是本次现场条件，不能可靠地由程序自动判断；显式记录可区分被动活体门禁失败、画质不足和彩光响应失败。

## 范围
仅影响彩光检测入口和失败诊断日志，不放宽 MiniFASNet 门禁，不改变彩光阈值结算。
