入口仍为项目根的 `attendance_ui.py`，请使用原有可运行该应用的 Python 环境。
`ui.py` 是原始演示入口，本轮未修改。

## 已实现
- 雾蓝、淡紫与樱粉点缀；原生星月装饰，没有下载素材或新增依赖。
- 四项侧边导航，保留原有页面实例和账户菜单接口。
- 实时签到的视频卡片、操作区、相机状态、识别结果与打卡反馈。
- 其他管理页面继承公共控件配色，但未进行第二阶段布局重做。

## 预览与验证
- `phase1-preview.png` / `phase1-1440.png`：1440×900。
- `phase1-1100.png`：1100×720。
- 截图由真实 Qt 控件离屏绘制，管理员为假数据，没有使用人脸照片。
- 独立验证：`python tests/test_anime_ui.py`，共 10 项 unittest；100% 与 200% 两轮均 9 项通过、1 项跳过。
- 可通过 `UI_PREVIEW_DIR` 指定截图目录；测试不读取数据库配置、不连接数据库、不加载模型。

- Windows 离屏插件若无法枚举字体，测试会加载系统已有微软雅黑；生产主题不包含机器绝对路径。

## 登录、弹窗与缩放修正
- 摄像头操作区新增「水平翻转」，默认开启，反转当前预览方向；取消显示设备原始方向。仅影响显示，不改变识别输入。该设置不跨启动保存。
- 登录、打卡确认、人员新增/编辑、改密、新增管理员统一主题，并按内容确定窗口最小尺寸。
- 侧栏与结果栏加宽并按实际字体宽度计算；结果姓名字号适当缩小。
- 应用级主题覆盖错误/确认提示；原生文件选择器和窗口标题栏保持系统样式。
- `dialog-*.png` 为五类弹窗预览；`scale-200/` 为两倍缩放预览。
- QMessageBox 构造在本机离屏插件下触发原生崩溃，该项未通过实机验收，测试明确跳过，不代表提示框显示已验证。

## 管理页统一
- 人员管理：页面说明、人数徽章、搜索操作卡、自适应表格。
- 打卡记录：页面说明、记录数量徽章、筛选条件卡、自适应表格。
- 管理员管理：页面说明、账号数量徽章、操作卡、自适应表格。
- 空表预览使用假 Service 返回，不代表生产数据库为空。

## 第三阶段：实时识别不卡顿
- YOLO/FaceNet 推理移到独立的短生命周期线程执行，摄像头预览仍由主线程持续刷新。
- 推理忙时丢弃新帧，不堆积任务，避免延迟不断增长。
- 停止识别、关闭摄像头或关闭窗口时会使已提交但过期的结果失效，并等待线程退出。
- 员工查询、确认打卡弹窗和状态反馈仍在主线程执行，识别规则与阈值保持不变。
