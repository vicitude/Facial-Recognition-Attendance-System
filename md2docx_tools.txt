局限:

  - 不渲染图片 (md 里的 ![](...))
  - 不渲染 HTML 标签

2. 转换脚本
----------------------------------------------------------------

脚本: D:\yol\yolov8_facenet\temp_md2docx.py

  执行命令: py temp_md2docx.py

  脚本功能:
    - 读 demo_report_leader.md / demo_report_member.md
    - 用 python-docx 解析 markdown 语法 (标题/表格/列表/代码块/引用/链接)
    - 输出 demo_report_leader.docx / demo_report_member.docx

  支持的 markdown 语法:
    # ~ ######    标题 (h1-h6)
    | a | b |    表格 (Light Grid Accent 1 样式)
    ```...```    代码块 (浅灰底色 + Consolas 等宽字体)
    `code`       行内代码
    **bold**     加粗
    *italic*     斜体
    [text](url)  链接 (蓝色下划线)
    - item       无序列表
    1. item      有序列表
    > quote      引用 (斜体 + 左缩进)
    ---          分隔线

  不支持 (直接当字符串处理):
    ![](image)   图片
    <html>       HTML 标签

3. 历史 / 备选方案
----------------------------------------------------------------

方案 A: python-docx (当前)      推荐, 轻量
方案 B: pypandoc + pandoc       质量最高, 但首次要下载 pandoc 二进制 (~50 MB)
方案 C: pandoc 命令行直转       质量最高, 需手动装 pandoc (~120 MB MSI)

本项目采用方案 A。

----------------------------------------------------------------
4. 未来如果要升级到 pandoc (方案 B/C)
----------------------------------------------------------------

下载: https://github.com/jgm/pandoc/releases
       选 pandoc-3.x-windows-x86_64.msi
默认安装路径: C:\Program Files\Pandoc\pandoc.exe

pip 路径 (方案 B):
   pip install pypandoc
   python -c "import pypandoc; pypandoc.download_pandoc()"

转换命令 (方案 C, 装好后):
   pandoc demo_report_leader.md -o demo_report_leader.docx --reference-doc=template.docx
