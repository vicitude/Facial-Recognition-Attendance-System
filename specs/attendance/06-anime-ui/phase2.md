# 登录、弹窗与高 DPI 布局补充规范

状态：用户于 2026-11-10 授权实施；本文件补充 spec.md，取代第一阶段固定侧栏/结果栏宽度及固定弹窗尺寸约定。

## 范围与问题
- 用户实机截图显示：侧栏标题换行、导航截断，右侧结果过度换行，打卡弹窗按钮文字遮挡。
- 原因：样式使用 pt 字体，容器及弹窗使用固定像素尺寸；登录在主窗口之前创建，未继承主题。
- 覆盖签到系统登录、打卡确认、新增/编辑员工、改密、新增管理员及 QMessageBox 提示。
- 操作系统原生文件选择器和窗口标题栏保留系统样式；原始 demo 与人脸库独立窗口不在本次范围。

## 实现契约
- QApplication 创建前设置 AA_EnableHighDpiScaling、AA_UseHighDpiPixmaps；应用创建后应用公共主题，启动错误弹窗同样处理。
- sidebar 宽度不小于 240，根据导航文字实际 QFontMetrics 宽度加 80 计算；禁用横向滚动，不让品牌标题换行。
- 结果卡宽度不小于 300，按正文提示宽度加 48 计算；姓名字号由 19pt 降为 17pt。
- 登录与所有自定义 QDialog 直接应用主题，不依赖父窗口是否存在；不再 setFixedSize，使用 minimumSizeHint 与 sizeHint 合并规定最小宽度。
- prepare_dialog(dialog, title, subtitle, primary_button, minimum_width=480) 设置水平 28px / 垂直 24px 边距、16px 间距、标题和说明、主按钮角色与内容适配尺寸。
- 登录保留用户名/密码控件与认证调用；无预填密码、无新增认证规则。回车提交使用默认登录按钮。
- 打卡仍四按钮（签到/签退/中间打卡/取消）；最小宽 560，按钮尺寸由内容和公共 padding 决定。
- StarBanner 高度与文字基线由字体度量决定，不使用固定文字坐标挤压内容。
- 不改数据库、服务规则、识别流程；保留 attendance_ui.py 已有用户改动。
- 人员、记录、管理员页面统一使用页面标题卡、说明/统计徽章、操作卡和自适应表格；原控件对象名、业务槽函数和筛选行为保持不变。

## 验证与边界
- 摄像头方向补充：用户反馈预览像镜子，新增「水平翻转」复选框，默认选中，以反转当前输入画面；取消即显示摄像头原始方向。仅影响预览，不修改检测/比对原始帧、不持久化设备设置。不声称已查明驱动镜像原因。
- 独立 unittest，不运行会清表的 pytest；模拟服务和模型。
- 验证登录成功/失败、改密/新建管理员/人员表单/确认框的按钮与字段包含于窗口。
- 验证侧栏文字宽度、结果卡提示宽度，100% 与 200% 缩放分别在独立进程运行。
- 保留真实 QMessageBox 主题与按钮几何测试；本机 offscreen 插件构造该控件时原生崩溃，离屏跳过并明确报告，桌面平台待验收。
- 离屏截图使用假数据，无真实人脸与数据库连接；真实显示器、摄像头和业务写入仍需用户现场确认。
- 管理页空状态预览不得误称为无真实数据；实际数据行仅由既有 Service 查询结果渲染。
