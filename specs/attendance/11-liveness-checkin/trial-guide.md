# 三次眨眼签到试运行

## 启动
先退出独立研究程序及其他占用摄像头的程序。在项目根的PowerShell启动：

```powershell
$env:PYTHONUTF8 = '1'
$env:YOLO_AUTOINSTALL = 'false'
$env:TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD = '1'
python -u .\attendance_ui.py
```

使用已验证的GPU虚拟环境解释器替换python（本机环境路径不在版本库固化）；TORCH开关仅用于本项目可信旧权重。不要用测试配置启动业务系统。

## 操作
1. 管理员登录。保持相机关闭，点击左侧“管理员管理”，在表格上方“活体验证设置”卡片点击胶囊按钮“活体试运行：关闭”，变为“活体试运行：开启”即生效；再次点击关闭。实时页同步显示状态。每次重新启动默认关闭，开关不持久化；账户菜单不再提供该入口。
2. 打开相机、开始识别。已登记加密三姿态模板的员工识别后进入其专属活体框。
3. 完成自然睁眼→闭眼→重新睁眼校准（不计次数）；再按中文提示做三次独立眨眼，每次后等身份复核。
4. 通过后才出现该员工的签到/签退确认，随后仍执行原班次/地点/重复与顺序规则；活体通过不等于打卡成功。
5. 多人按检测顺序逐人进入，每人独立校准和三次眨眼。请其余人员暂时移出画面，活体阶段要求恰好一张脸。
6. 取消、失败、90秒总超时、模型/模板异常均不进入确认，不写本次考勤；关闭后可重新开始识别。没有失败时自动绕过。
7. 关闭相机后才能修改试运行开关；关闭开关恢复原确认流程，但这不是通过活体。

## 验收边界
自动化仅隔离测试库、模型与相机替身验证；尚未做系统内真实GPU/摄像头端到端验收。真人、完整纸质照片、手机静态照片各20轮（至少两种光照/距离，含移动纸张/屏幕），真人至少18通过、两类攻击各0通过才可讨论默认启用；手机视频/挖眼照片/深伪不作防护承诺。当前仍默认关闭。

相机复用父页面资源，活体框不release父capture；父预览暂停，活体框GUI定时器唯一读取，推理后台进行，退出等待推理释放后恢复预览。硬件read本身仍可能阻塞GUI，后台模型调用不可强制安全中断；不宣称实现硬实时取消。
